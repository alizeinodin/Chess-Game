## تغییرات نسبت به رزومه عمومی بک‌اند

1. **عنوان شغلی** روی C++ / Qt و اپلیکیشن دسکتاپ تنظیم شده
2. **مهارت‌های Qt/QML** در بالای رزومه آمده (Signals/Slots، Q_PROPERTY، Material، CMake/qmake)
3. **Bu-Ali Chess** به‌عنوان پروژه شاخص با جزئیات فنی قابل فروش بازنویسی شده
4. تجربه Laravel/MCI حفظ شده، ولی به‌عنوان اثبات تحویل حرفه‌ای و معماری — نه تمرکز اصلی
5. یک جمله هدف همکاری در پایین رزومه برای جذب پروژه Qt اضافه شده
